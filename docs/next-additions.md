# Three proposed next additions

These are design proposals for later approval. None is implemented in this branch, and no retention or learning uplift has been measured.

## 1. Daily case file

Offer one reproducible daily mystery with the same questions for everyone, an optional friend-group results board, and a shareable completion card. A seed based on the case date makes scores comparable within the same math level and time pressure. Keep ordinary room-code matches available.

Why: gives returning groups a clear reason to start a new match beyond replaying the same route. First version: one daily seed and local completion history; avoid requiring accounts. Evaluate return visits and completion rate against ordinary fresh-number matches before expanding.

## 2. Split-clue Co-op puzzles

Add optional puzzles where teammates receive complementary evidence: one sees a family relationship, another sees a route instruction, and both need to explain their clue. Scale evidence distribution to the connected human count and provide a recovery path if a player disconnects. Keep Race questions identical and independent.

Why: turns the team channel into part of solving rather than just a chat box. First version: one split-evidence lock per Co-op room, with text/diagram alternatives. Evaluate participation across teammates, abandonment after disconnects, and whether players understand the task without facilitator help.

## 3. Personal mastery notebook

After a match, collect missed concepts and offer untimed practice questions with fresh values and step-by-step explanations. Store progress in the player’s browser first. Let the player pick a topic; later, use recent accuracy and response time to suggest practice without silently making competitive matches easier for one racer.

Why: makes mistakes useful and gives students a gentler way to prepare for the next race. First version: topic recap plus retry questions, no model or external API needed. Evaluate retry completion and accuracy on a later fresh question; describe results as observed outcomes rather than promising learning gains.
